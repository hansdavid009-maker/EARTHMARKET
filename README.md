# RedMandarin — Platform Belanja & Penukaran Rupiah ke Yuan

Platform terpadu untuk belanja produk China, simulasi penukaran Rupiah ke Yuan, kamus Mandarin interaktif, dan asisten AI cerdas.

## Fitur Utama
1. **E-Commerce Toko Produk China**: Adapter listrik China, kartu eSIM bypass firewall, alat AI voice translator, suvenir teh & kaligrafi.
2. **Kalkulator Kurs & Exchange**: Konversi dua arah IDR ↔ CNY dengan perhitungan transparan kurs dan biaya admin.
3. **Kamus Mandarin Interaktif**: 10 Kategori, karakter Hanzi, Pinyin berharakat, dan pelafalan audio Text-to-Speech (TTS).
4. **AI Assistant**: Floating chatbot untuk rekomendasi belanja, cek kurs valas real-time, dan cek status pesanan.
5. **Dashboard & Admin**: Pelacakan pesanan, riwayat penukaran uang, dan kontrol panel admin.

## Menjalankan di Lokal
```bash
npm install
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000).

## Cara Deploy Online Selamanya (Gratis di Vercel)
1. Buka [https://vercel.com](https://vercel.com) dan masuk dengan akun GitHub / Google Anda.
2. Unggah folder ini ke repository GitHub atau gunakan command:
   ```bash
   npx vercel
   ```
3. Website Anda langsung online selamanya dengan domain `https://redmandarin.vercel.app` bersertifikat SSL resmi.
